# Illustrated installation guide, without photo backgrounds

Replaces the photo-based introduction with six manual pages: account identification, verification/PIN safety, wallet balances/history, transfers, QR scanning, and available services (including the authorized agent space).

All backgrounds are black and extend behind the system bars. Drawings use Compose containers and Material vector icons; no generated photo, screenshot, artificial balance or account card appears. Each diagram has three numbered actions and arrows. The text area scrolls on small displays while Back/Next remain separate. A six-segment progress indicator and page counter remain visible. Only the final page offers Start; no early Skip action can accidentally end the guide.

The v6 completion preference displays the revised guide once on update, even if an earlier version was completed. Previous photo crops were removed from Android resources. The previous photo-based guide document describes the superseded version.
